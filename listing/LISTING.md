## Description

**A complete studio website you can rebrand in an afternoon.**

This template ships in two forms, so you are not locked into one tool: a Framer
code component you edit visually, and the same site as a single standalone HTML
file you can upload to any host.

**Fully editable in Framer**

Everything is a control in the properties panel — no code to touch. Thirteen
panels, in the order the sections appear on the page: Navbar, Global Style,
Hero, Stats, About, Services, Process, Materials, Portfolio, Testimonials, FAQ,
Contact, Footer.

Change the accent colour and the whole site follows: buttons, links, gradients,
icons, timeline, focus rings. There is a reset switch that puts the original
palette back if you go too far.

**Built to be rebranded**

Nothing in the layout is tied to 3D printing. Upload your own service icons and
it becomes a restaurant, a garage, a photo studio, a furniture workshop. Each
portfolio project has three spec rows you name yourself — Print Time / Weight /
Material for a workshop, Wood / Finish / Lead time for a joiner, Location /
Camera / Turnaround for a photographer.

Ten content sections each have an on/off switch. Use three of them or all ten;
the page closes the gap on its own.

**What you get**

- A one-click Framer duplicate link — the finished project lands in your account
- `AbcLabSite.tsx` — the same component as a file, for existing projects
- `abclab-mockup.html` — the same site as one self-contained file
- `photos/` — nine product photos, six studio shots plus three with the
  background already cut out
- `START-HERE.md` and `GUIDE.md` — setup, section by section, plus how to move it
  to another trade

**Also included in the design**

- Responsive from 390px up, tested on phone and desktop
- Rotating hero photos with no background, so they float on the page
- Portfolio pop-up with previous/next navigation
- Contact form that opens the visitor's mail app — no server, no form service,
  no monthly fee
- Map that takes a street address, tinted in your brand colour
- Respects reduced-motion settings for visitors who need them

**Requirements**

A Framer account is needed for the `.tsx` component. The HTML file needs
nothing — open it in any browser, or rename it to `index.html` and upload it to
any host.

**Delivery**

Instant digital download. No physical item is shipped.
