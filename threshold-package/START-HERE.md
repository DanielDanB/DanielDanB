# Start here

There are two ways to get this template into Framer. The first takes one click.

---

## The quick way — duplicate the ready-made project

**Your link:**

> `PASTE YOUR FRAMER DUPLICATE LINK HERE`

1. Open the link while signed in to Framer.
2. Framer asks whether you want to duplicate the project. Confirm.
3. The project appears in your own account, with the component already placed on
   the canvas and all eight demo properties filled in.
4. Select the component and start editing in the panel on the right.

Nothing to paste, nothing to install. What you get is the finished demo site,
which you then rewrite into your own agency.

This link is for you. It lets anyone who has it copy the whole project, so please
do not post it publicly.

---

## The manual way — add the component to a project you already have

Use this if you want the template inside an existing Framer project rather than a
new one.

1. Open your Framer project.
2. In the Assets panel, click **+ → Code File** and name it `ThresholdSite`.
3. Delete the placeholder code, paste in the whole contents of
   `ThresholdSite.tsx`, and save.
4. Drag the component from Assets onto your canvas.
5. Set its width to **Fill** and its height to **Auto**.

Both routes give you exactly the same component. The first just saves you the
paste.

---

## Not using Framer?

`threshold-mockup.html` is the same site as a single standalone file. Rename it to
`index.html`, upload it to any hosting, and it works — no build step, no account,
nothing to install.

---

## The first five minutes

Open **⑥ Listings**, click the first property, and change its Title, Neighborhood
and Price. Then open **⑫ Agent** and put your own name, phone and email in. That
is enough to see the whole site become yours; everything else is refinement.

Full instructions for every section are in **Full guide.pdf**.
